# RScripter
this is a port for the [ONScripter](https://github.com/Galladite27/ONScripter-EN) platform, a community-made open-source C++ interpretation for the original [NScripter](https://en.wikipedia.org/wiki/List_of_visual_novel_engines#NScripter) [visual novel](https://en.wikipedia.org/wiki/Visual_novel) engine by Naoki Takahashi.

tools:
[Rojo](https://github.com/rojo-rbx/rojo) 7.6.1
thats it

## Usage
build the project with rojo (there will probably be a build when this is finished just incase)
```bash
rojo build -o "NScripter.rbxlx"
```
